# Community Hospital — first review

This is a small, self-contained synthetic learning case for OmegaClaw Launchpad Studio.
It shows how two agents can disagree about a care-routing question while a
human keeps the final say.

## Important limitation

Every person, note, fact, and result in this template is fictional. This is
not medical advice, a diagnosis, a patient record, or a recommendation for a
real care decision. It does not validate outside data, send a message, change
a record, or deny care.

## Files

- `facts.json` contains fictional, recorded observations.
- `rules.md` is the human-readable lesson rule.
- `rules.metta` is an Illustrative MeTTa lesson scaffold; Studio does not
  claim that this scaffold is a reviewed production rule.
- `tests.json` contains one review-needed case and one safe observation case.
- `example-receipt.md` is a fixture, not runtime evidence.
- `workspace.json` describes the fixed files in this workspace.

Copy this lesson into a private workspace, then ask your agent to adapt it to
one bounded question while preserving the human-review boundary.

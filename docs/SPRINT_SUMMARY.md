# OmegaClaw Launchpad V2

V2 is a Docker-only learning and evidence path for OmegaClaw-Core. A newcomer follows one short parable — **The Lighthouse in the Fog** — then sees the same idea backed by a real pinned OmegaClaw run.

The run uses the Test provider and WebSocket channel, proves memory across restart, a local tool, MeTTa, NAL/STV, a response, and a receipt. Facts are synthetic, no external action occurs, and a human remains responsible for any decision.

The Wizard starts only after preflight and proof. Its final step points a coding agent to `examples/lighthouse-in-the-fog/`, where the story, claims, facts, provenance, rules, reasoning lesson, tests, and agent-facing Markdown are ready.

MCP is optional: a small local STDIO plug for consulting verified evidence and retrieving receipts. It is not a general multi-agent router or an action authority.

See [STUDIO.md](STUDIO.md), [PROOF.md](PROOF.md), [AGENT_GUIDE.md](AGENT_GUIDE.md), and [THE_LIGHTHOUSE_IN_THE_FOG.md](THE_LIGHTHOUSE_IN_THE_FOG.md).

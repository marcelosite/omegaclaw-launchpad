# V2 Feynman journey

## The idea in one sentence

OmegaClaw receives recorded reports, remembers them, checks their evidence, reasons over a human rule, and explains a recommendation; a person decides.

## The parable

A boat is looking for a harbor in fog. One beacon says the way is clear, a sailor reports an obstacle, and another beacon is silent. OmegaClaw keeps the reports, remembers yesterday's driftwood note, reads one identified harbor bulletin, preserves the disagreement, updates its reasoning when verified evidence arrives, and leaves a receipt. It never steers the boat.

## The eight moments

1. Intro — start with the story and the reason for following it.
2. Input — an input is not truth.
3. Memory — persisted memory can be queried after restart.
4. Verify — source and time stay attached to a fact.
5. Reason — MeTTa and NAL/STV make revision visible.
6. Explain — recommendation, unknowns, confidence, and receipt are readable.
7. Understand — show the full story-to-system map.
8. Play — a coding agent gets one safe, runnable prompt.

## Z-reading rules

Every lesson screen keeps the story on the left and the matching technical term, plain explanation, and minimal proof on the right. Progress is linear and not clickable. Setup commands run before the Wizard in a terminal; MCP is never a gate.

## Honest scope

The Docker proof is real and pinned, but its facts and provider are synthetic. It demonstrates an integration path, not every OmegaClaw capability, external-data validation, production autonomy, or a safe action decision. GIGO means **Garbage In, Garbage Out**: reasoning quality cannot repair false or missing input.

# V2 submission summary

OmegaClaw Launchpad V2 is a Docker-only onboarding and evidence layer. Its single story, **The Lighthouse in the Fog**, maps one understandable situation to a real pinned OmegaClaw run.

The acceptance path proves the loop, persistent memory across restart, a controlled file tool, MeTTa, NAL/STV, an explanation, a receipt, and the safety boundary (`human_approval_still_required: true`, `external_actions: []`).

The Wizard starts only after preflight and proof, uses eight short story moments, and ends with a ready-to-copy prompt for Codex, Claude Code, or another coding agent. MCP is optional and bounded to two local receipt tools; it is not an autonomous router.

See [PROOF.md](PROOF.md), [STUDIO.md](STUDIO.md), and [AGENT_GUIDE.md](AGENT_GUIDE.md).

## Short project-page description

OmegaClaw Launchpad turns a complex neural-symbolic agent framework into one short, verifiable first experience. A new user points a coding agent to the repository, runs one Docker-only launcher, sees the real pinned OmegaClaw runtime pass a deterministic no-key proof, and then learns the system through **The Lighthouse in the Fog**. The proof covers the WebSocket loop, memory across restart, a controlled file tool, MeTTa, NAL/STV reasoning, an explanation, and a hashed receipt. The result is evidence before autonomy: OmegaClaw recommends, a person decides, and no external action is performed.

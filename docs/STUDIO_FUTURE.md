# Future direction

The active product is the eight-moment, story-first Lighthouse journey described in [STUDIO.md](STUDIO.md). Future work must preserve Docker-only setup, immutable evidence, least privilege, explicit human approval, and the distinction between observation, inference, and action.

Possible extensions are versioned rulebooks, structured fact editing, receipt redaction, authenticated adapters, and Linux CI. None should turn Studio into an autonomous action service.

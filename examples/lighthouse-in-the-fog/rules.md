# Human-owned Lighthouse rule

1. When current sources conflict or required route information is missing,
   conclude `gather_more_evidence`.
2. When two current, independent, identified sources support the same route,
   conclude `north_route_supported_for_human_review`.
3. Always preserve the sources, truth values, unknowns, and reasoning result.
4. Never steer the boat, activate a navigation signal, or send an external
   message from the conclusion alone.

The conclusion is a recommendation for a fictional lesson. A person remains
responsible for every real-world decision and action.

# Coding-agent contract for this example

Read `README.md`, `story.md`, `facts.json`, `rules.md`, `reasoning.metta`, and
`tests.json` before changing a copied workspace.

1. Work only in a private copy; do not edit the canonical gold example.
2. Keep claims, recorded facts, provenance, human rules, executable reasoning,
   tests, runtime evidence, and receipts separate.
3. Preserve at least one conflict case, one agreement case, one missing-fact
   case, and one GIGO case.
4. Preserve `human_approval_required: true` and `external_actions: []`.
5. Never turn the fixture receipt into verified evidence.
6. Run the fast example checks before proposing a real Docker proof.
7. Show the human the diff, test result, limitations, and receipt.
8. Do not add credentials, networking, shell actions, or external messages.

See `../../docs/AGENT_GUIDE.md` for the repository-wide workflow.
